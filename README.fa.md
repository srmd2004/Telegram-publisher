# پنل انتشار تلگرام، بله، ایتا و اینستاگرام

## نکات مهم
- توکن‌ها را فقط در Render → Environment وارد کنید؛ هرگز در GitHub، فایل‌های `public/app.js` یا پیام عمومی قرار ندهید.
- تلگرام، بله و ایتا برای انتشار در کانال باید ربات/برنامه مجاز داشته باشند و در کانال دسترسی مدیرِ ارسال پست دریافت کرده باشند.
- اتصال ایتا در این نسخه از API ایتایار استفاده می‌کند؛ شرایط دسترسی/اعتبار حساب ایتایار ممکن است اعمال شود.
- اینستاگرام فقط برای حساب حرفه‌ای Business یا Creator از API رسمی پشتیبانی می‌شود. این نسخه از Instagram Login استفاده می‌کند و به `instagram_business_basic` و `instagram_business_content_publish` نیاز دارد.
- اینستاگرام پست فقط متنی ندارد. عکس باید JPEG باشد و ویدئو به شکل MP4/MOV برای Reels ارسال می‌شود.
- برای اینکه Meta فایل را دریافت کند، سرور یک URL تصادفی و موقت روی همین Render ایجاد می‌کند؛ فایل در حافظه نگه داشته می‌شود و پس از انتشار حذف می‌شود. این لینک را عمومی به اشتراک نگذارید.
- این بسته از نظر نحوی بررسی شده، اما ارسال واقعی به حساب‌های شما تا وارد کردن توکن‌ها و تست مقصدها تأییدشده محسوب نمی‌شود.

## فایل‌ها را جایگزین کنید
1. ابتدا از مخزن GitHub نسخه پشتیبان بگیرید یا یک branch جدا بسازید.
2. محتوای این بسته را در ریشه مخزن `Telegram-publisher` قرار دهید و فایل‌های هم‌نام را جایگزین کنید.
3. مطمئن شوید `server.js` و `package.json` در ریشه و سه فایل رابط کاربری داخل پوشه `public` قرار دارند.
4. تغییرات را commit کنید. Render باید به‌طور خودکار deploy کند.

## تنظیمات Render → Environment
مقادیر واقعی را در Environment وارد کنید:

- `ADMIN_USERNAME` — نام کاربری پنل فعلی
- `ADMIN_PASSWORD` — رمز قوی پنل فعلی
- `TELEGRAM_BOT_TOKEN` — توکن فعلی ربات تلگرام
- `TELEGRAM_CHAT_ID` — شناسه یا `@username` کانال تلگرام
- `BALE_BOT_TOKEN` — توکن ربات بله
- `BALE_CHAT_ID` — شناسه یا `@username` کانال بله، مطابق API بله
- `EITAA_BOT_TOKEN` — توکن صادرشده از ایتایار
- `EITAA_CHAT_ID` — شناسه کانال ثبت‌شده در ایتایار یا شناسه‌ای که سرویس ایتایار می‌پذیرد
- `INSTAGRAM_ACCESS_TOKEN` — Access Token رسمی Instagram Login
- `INSTAGRAM_USER_ID` — شناسه حساب حرفه‌ای اینستاگرام
- `INSTAGRAM_GRAPH_BASE` — `https://graph.instagram.com/v26.0`؛ در صورت نیاز با نسخه پشتیبانی‌شده حساب Meta خود هماهنگ کنید
- `PUBLIC_BASE_URL` — `https://telegram-publisher1.onrender.com`

بعد از تغییر Environment، Render را redeploy/restart کنید.

## ایجاد اتصال هر پلتفرم

### تلگرام
از توکن و شناسه فعلی استفاده کنید. ربات باید در کانال مدیر و مجاز به انتشار پیام باشد.

### بله
از مسیر رسمی توسعه‌دهندگان بله و BotFather داخل بله برای ساخت/دریافت توکن ربات اقدام کنید. ربات را به کانال اضافه و مجوز ارسال پست را بدهید. سپس توکن و شناسه مقصد را در Environment بگذارید.

### ایتا
این نسخه از API ایتایار (`eitaayar.ir`) استفاده می‌کند. حساب/برنامه را در ایتایار تنظیم کنید، توکن را از همان پنل بگیرید، کانال را ثبت کنید و ربات/برنامه را به‌عنوان مدیر دارای دسترسی انتشار اضافه کنید. در صورت نیاز به اعتبار یا تأیید ایتایار، آن را در همان سرویس تکمیل کنید.

### اینستاگرام
1. حساب Instagram باید Business یا Creator باشد.
2. در Meta for Developers یک App ایجاد کنید و Instagram API with Instagram Login را راه‌اندازی کنید.
3. مجوزهای `instagram_business_basic` و `instagram_business_content_publish` را اعطا کنید.
4. Access Token و Instagram professional account ID را دریافت کنید.
5. این سه مقدار را در Render وارد کنید: `INSTAGRAM_ACCESS_TOKEN`، `INSTAGRAM_USER_ID` و `PUBLIC_BASE_URL`.
6. برای حساب‌های بیرون از نقش‌های توسعه/آزمایش برنامه، ممکن است بررسی و دسترسی‌های پیشرفته Meta لازم باشد.

## تست ایمن
1. ابتدا فقط تلگرام را انتخاب و یک متن کوتاه ارسال کنید.
2. بله و ایتا را جداگانه با متن آزمایش کنید.
3. اینستاگرام را با یک عکس JPEG کوچک و کپشن کوتاه آزمایش کنید.
4. بعد از موفقیت مقصدها را با هم انتخاب کنید.
5. اگر یک مقصد خطا داد، نتیجه هر مقصد در صفحه جدا نمایش داده می‌شود؛ موفقیت مقصدهای دیگر حفظ می‌شود.

## محدودیت رسانه
- حجم فایل ارسالی از پنل: حداکثر 50 MB.
- عکس تلگرام: این نسخه حداکثر 10 MB.
- عکس اینستاگرام: JPEG، حداکثر 8 MB.
- اینستاگرام برای ویدئو از MP4/MOV و Reels استفاده می‌کند.
- فایل موقت اینستاگرام روی حافظه سرور ذخیره می‌شود؛ restart هم‌زمان سرویس ممکن است دریافت فایل را مختل کند.
