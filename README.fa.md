# Telegram Publisher — نسخه امن با آپلود مستقیم عکس و فیلم

این نسخه برای انتشار پیام متنی، عکس و فیلم در کانال تلگرام است. فایل انتخابی از مرورگر مستقیماً به سرور می‌رسد و سرور آن را با multipart/form-data به Telegram Bot API می‌فرستد؛ نیازی به آپلود فایل در سرویس دیگری یا کپی URL نیست.

## فایل‌هایی که باید جایگزین شوند
- `server.js`
- `package.json`
- کل پوشه `public/` (شامل `index.html`، `style.css` و `app.js`)

ابتدا از نسخه فعلی مخزن نسخه پشتیبان بگیر. این جایگزینی رابط کاربری قبلی را با پنل ساده فارسی این بسته عوض می‌کند.

## متغیرهای Render
در Service > Environment این مقادیر را تنظیم کنید:
- `ADMIN_USERNAME`: نام کاربری مدیر
- `ADMIN_PASSWORD`: رمز قوی و منحصربه‌فرد
- `TELEGRAM_BOT_TOKEN`: توکن ربات
- `TELEGRAM_CHAT_ID`: شناسه کانال، مثلاً `@channelusername`

توکن و رمز واقعی را در GitHub commit نکنید. از HTTPS سرویس Render استفاده کنید.

## انتشار
1. فایل‌های بالا را در شاخه `main` جایگزین و commit کنید.
2. Render باید به‌طور خودکار deploy کند؛ در غیر این صورت Manual Deploy را اجرا کنید.
3. در Logs بررسی کنید که سرور بدون خطا بالا آمده باشد.
4. سایت را باز کنید؛ مرورگر پنجره نام کاربری و رمز عبور را نمایش می‌دهد.
5. یک پیام متنی، یک عکس کوچک و یک فیلم MP4 کوچک آزمایش کنید.

## محدودیت‌ها
- پیام متنی: حداکثر 4096 نویسه.
- کپشن عکس/فیلم: حداکثر 1024 نویسه.
- عکس: حداکثر 10 MB برای این پیاده‌سازی.
- فیلم: حداکثر 50 MB و فرمت‌های متداول MP4/MOV/WEBM؛ پشتیبانی واقعی فرمت می‌تواند به کدک و تلگرام بستگی داشته باشد.
- فایل‌ها موقتاً در حافظه سرور نگهداری می‌شوند و روی دیسک ذخیره نمی‌شوند. Render Free دارای فایل‌سیستم موقتی است؛ در این برنامه فایل‌ها پس از پردازش در حافظه باقی نمی‌مانند.
- این نسخه از HTTP Basic Authentication استفاده می‌کند، نه فرم اختصاصی ورود. از آن فقط روی HTTPS استفاده کنید.
