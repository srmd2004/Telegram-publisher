# نسخه امن Telegram Publisher

این مجموعه شامل `server.js` و `package.json` سازگار با Express 5 است. فایل‌های رابط کاربری قبلی داخل پوشه `public/` پروژه فعلی باید حفظ شوند و نباید حذف شوند.

## متغیرهای Environment در Render

این مقادیر را در بخش Environment سرویس Render تعریف کنید:

- `ADMIN_USERNAME`: نام کاربری مدیر
- `ADMIN_PASSWORD`: رمز عبور قوی و منحصربه‌فرد
- `TELEGRAM_BOT_TOKEN`: توکن ربات تلگرام
- `TELEGRAM_CHAT_ID`: شناسه کانال یا گفت‌وگوی مقصد

مقادیر واقعی را در GitHub یا در فایل‌های مخزن قرار ندهید. در صورت استفاده محلی، یک فایل `.env` بسازید و آن را commit نکنید.

## نصب و اجرا

```bash
npm install
npm start
```

نیازمند Node.js نسخه 18 یا بالاتر است. روی Render از HTTPS استفاده کنید.

## نکات

- HTTP Basic Authentication تمام سایت و API را محافظت می‌کند؛ مرورگر پنجره ورود خودش را نمایش می‌دهد.
- محدودکننده API پیش از احراز هویت اجرا می‌شود تا درخواست‌های نامعتبر نیز محدود شوند.
- برای پیام متنی حداکثر 4096 نویسه و برای کپشن عکس حداکثر 1024 نویسه مجاز است.
- فایل‌های فعلی `public/index.html`، `public/app.js` و `public/style.css` را حفظ کنید.
- این نسخه از فرم ورود اختصاصی یا دکمه خروج استفاده نمی‌کند.
