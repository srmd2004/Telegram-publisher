# مدیر انتشار تلگرام — نسخه اولیه

این نسخه یک وب‌اپلیکیشن ساده است که از داخل پنل، متن یا متن همراه با لینک تصویر را در یک کانال تلگرام منتشر می‌کند. در این مرحله، دریافت خودکار پست از تلگرام و انتشار در شبکه‌های دیگر پیاده‌سازی نشده است.

## پیش‌نیازها
- Node.js نسخه 20 یا بالاتر
- یک ربات تلگرام و توکن آن
- کانال تلگرام مقصد

## راه‌اندازی محلی
1. فایل ZIP را استخراج کن.
2. در پوشه پروژه، ترمینال را باز کن.
3. دستور `npm install` را اجرا کن.
4. فایل `.env.example` را به `.env` کپی کن.
5. مقدار `TELEGRAM_BOT_TOKEN` را با توکن ربات و `TELEGRAM_CHAT_ID` را با شناسه کانال جایگزین کن.
6. اجرا کن: `npm start`
7. در مرورگر باز کن: `http://localhost:3000`

## آماده‌سازی ربات و کانال
1. در تلگرام به `@BotFather` پیام بده و با دستور `/newbot` ربات بساز.
2. توکن ربات را محرمانه نگه دار؛ آن را برای کسی نفرست و داخل کد فرانت‌اند قرار نده.
3. ربات را به کانال مقصد اضافه کن و دسترسی لازم برای ارسال پیام بده؛ معمولاً باید مدیر کانال باشد.
4. اگر کانال نام کاربری عمومی دارد، مقدار `TELEGRAM_CHAT_ID` می‌تواند به شکل `@channelusername` باشد. برای کانال خصوصی، شناسه عددی معتبر لازم است.
5. ابتدا یک پیام آزمایشی منتشر کن.

## نکات امنیتی مهم
- این نسخه برای آزمایش اولیه است و هنوز ورود کاربران، احراز هویت مدیریتی، HTTPS اجباری در محیط تولید، و مدیریت چند کاربر را ندارد؛ آن را بدون افزودن این موارد مستقیماً روی اینترنت عمومی منتشر نکن.
- فایل `.env` را به کسی نده و در مخزن Git بارگذاری نکن.
- محدودیت درخواست ساده‌ای برای API گذاشته شده است، اما جایگزین احراز هویت نیست.
- اگر توکن افشا شد، آن را از طریق BotFather تعویض کن.

## محدوده فعلی
- انتشار متن
- انتشار تصویر از طریق URL عمومی به همراه کپشن
- نمایش وضعیت تنظیمات و نتیجه ارسال
- محدودیت متن و نرخ درخواست

## مرحله بعد
پس از تست موفق، احراز هویت، آپلود مستقیم عکس/ویدئو، تاریخچه انتشار و سپس اتصال شبکه‌های دیگر اضافه شود.
